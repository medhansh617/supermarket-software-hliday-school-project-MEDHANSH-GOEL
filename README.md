# Supermarket Management System

## Overview
This is a Python-based Supermarket Management System developed using Tkinter. It provides a graphical user interface for managing supermarket operations.

## Features
- Login System
- Inventory Management
- Add Products
- Delete Products
- Billing System
- Calculate Total Bill
- Sales Section

## Technologies Used
- Python
- Tkinter
- Pillow (PIL)

## How to Run

1. Install Python 3.
2. Install Pillow:

```bash
pip install pillow
```

3. Run the program:

```bash
python "supermarket software.py"
```
